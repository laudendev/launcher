# Lauden Launcher

Enter your license key to download and manage software you've purchased from Laudenslager Software, LLC.

## Install

1. Extract this archive:
       tar -xzf lauden-dev-launcher-linux.tar.gz

2. Move the binary to a directory in your PATH:
       mv lauden-dev-launcher/lauden-dev-launcher ~/.local/bin/

3. (Optional) Add the app menu entry:
       mkdir -p ~/.local/share/applications
       cp lauden-dev-launcher/lauden-dev-launcher.desktop ~/.local/share/applications/

4. Run it:
       lauden-dev-launcher

## How it works

No accounts, no sign-in. Enter the license key emailed to you at purchase. Activating on a device is a one-time online step — after that, the software runs entirely offline for as long as you use it.

Each license includes a fixed number of seats. You can deactivate a device at any time to free its seat for another device — including transferring it to someone else, the same way you'd resell a physical copy of software.
